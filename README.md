# Pizza Shop

**Pizza Shop** is a responsive pizza ordering website built with HTML, CSS, and JavaScript. It was my **first-ever development project** and helped me build a strong foundation in frontend development and JavaScript.

🔗 **Live Demo:** https://pizza-shop-five-lac.vercel.app/

## Features

* Interactive pizza menu
* Add-to-cart functionality
* Increase and decrease item quantities
* Dynamic cart total calculation
* Checkout functionality
* Responsive design
* Interactive navigation and UI

## Tech Stack

**Frontend:** HTML5, CSS3, JavaScript
**Deployment:** Vercel

## Challenge & Learning

The main challenges were making the website **responsive across different screen sizes** and implementing the cart and checkout logic using JavaScript.

Working on the cart helped me understand **DOM manipulation, event handling, arrays, dynamic calculations, and managing application state on the frontend**.

## Outcome

Pizza Shop was my first complete web development project and gave me a strong foundation in **HTML, CSS, JavaScript, responsive design, and frontend development**.

It was the project that got me started with building interactive web applications and eventually led me toward full-stack development.
